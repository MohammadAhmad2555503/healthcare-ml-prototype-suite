# Portfolio Card: Breast Cancer AI

**Repo:** breast-cancer-ai

**One-liner:** Healthcare ML prototype for breast cancer prediction with Streamlit dashboard, model comparison, explainability, Docker, and tests.

**Employer signal:** Shows end-to-end ML product delivery: data validation, training, evaluation, explainability, UI, packaging, and testing.

**Tech:** Python, Streamlit, Scikit-learn, XGBoost, LightGBM, CatBoost, SHAP, Docker, Testing

**Best proof points:**
- Covers validation, EDA, model comparison, tuning, metrics, SHAP explainability, and Streamlit delivery.
- Includes Docker/Compose packaging and tests, making it more complete than a typical modelling notebook.
- Dependency environments, logs, caches, and generated runtime outputs were excluded.
- Clear safety framing marks it as an educational prototype, not a clinical product.
