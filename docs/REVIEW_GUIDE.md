# Review Guide

This guide helps a busy reviewer inspect the suite quickly.

## Five-Minute Review

1. Read the root `README.md`.
2. Open `PROJECTS.md`.
3. Inspect `EMPLOYER_SHOWCASE.md`.
4. Pick one structured-data project and one imaging project.

Recommended pair:

- `projects/heart-disease-risk-assessment/`
- `projects/brain-tumor-detection-system/`

## Fifteen-Minute Review

Inspect:

- `projects/heart-disease-risk-assessment/src/`
- `projects/breast-cancer-decision-support/app/`
- `projects/brain-tumor-detection-system/reports/`
- `projects/eye-disease-screening-system/tests/`

Look for project organization, repeatable setup, test coverage, reporting, and how the dashboard layer connects to reusable code.

## Deeper Review

Compare the focused prototypes with the workflow-oriented system projects:

- Focused prototypes: `breast-cancer-ai`, `brain-tumour-ai`, `eye-disease-ai`, `heart-disease-ai`, `lung-cancer-ai`
- Workflow systems: `brain-tumor-detection-system`, `breast-cancer-decision-support`, `eye-disease-screening-system`, `heart-disease-risk-assessment`, `lung-cancer-imaging-system`

This comparison shows how similar engineering patterns can be adapted across domains.
