## Recommended Review Order

1. projects/heart-disease-risk-assessment/ for structured clinical prediction and clear risk-review flow.
2. projects/breast-cancer-decision-support/ for decision-support structure and explainability-oriented review.
3. projects/brain-tumor-detection-system/ for imaging workflow and reporting.
4. projects/eye-disease-screening-system/ for screening-system organization.
5. projects/lung-cancer-imaging-system/ for another imaging domain with similar engineering patterns.

## Notes

- Each project remains self-contained so a reviewer can inspect source, tests, docs, reports, Docker files, and setup files independently.
- The suite-level files help employers understand the overall portfolio quickly.
- Runtime folders, caches, logs, local databases, and nested repository metadata are intentionally excluded.
